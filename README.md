# galelagja

Portfolio for [@galelagja1](https://www.instagram.com/galelagja1/) on Instagram: Bollywood song reels.

Live: https://galelagjao.vercel.app/

## Updating the page

Everything lives in `index.html`. Near the bottom:

- `CONFIG` holds the handle, follower count, stats date and an optional email (the Email button shows only when it's set).
- `REELS` lists every reel, newest first. Add a line for a new reel and save its cover as `assets/reels/<reel id>.jpg`. Totals, averages and the top-reels grid update on their own.
